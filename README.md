# Melons Death Mod (Geode mod)

## Build (easiest: GitHub Actions)
1. Make a new GitHub repo and upload everything in this folder.
2. Open the **Actions** tab -> *Build Mod* -> wait for it to finish.
3. Download the `.geode` file from the build output and drop it in `Geometry Dash/geode/mods/`.

## Build locally
Install the Geode CLI + SDK, then:
    geode build
